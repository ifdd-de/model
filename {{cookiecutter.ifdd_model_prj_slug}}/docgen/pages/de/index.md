# Namensräume

Je Namensraum dieses Modells eine Seite, erzeugt aus seiner LinkML-Quelle.
Die Seite „Von LinkML zu JSON-LD“ der Betriebsdokumentation erklärt, wie aus
LinkML-Elementen JSON-LD wird.

## Namensräume des type-Dienstes

```{toctree}
:maxdepth: 1
:glob:

type/*
```
